# Parkhaus-Managementsystem
Ein Parkhaus-Managementsystem in Python zur Verwaltung von Fahrzeugen, Parkgebühren und Kapazitäten. Das Projekt demonstriert Vererbung, Polymorphismus, abstrakte Klassen (ABC), benutzerdefinierte Exceptions, Generatoren und Dunder-Methoden.
